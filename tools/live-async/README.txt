Live asynchronous decoding: build and validation tools
=======================================================

Start with doc/live-async-guide-zh.txt for service integration and source porting.
The public API is libavcodec/async.h; design is in doc/live-async-decoding.txt.

build-linux.sh / build-msys2.sh
    Build the modified 7.0.3 shared libraries and both probes. Default output
    directories end in linux-async / msys2-async, preserving frozen baselines.
    Linux objects live in XDG_CACHE_HOME/ffmpeg-live, falling back to HOME/.cache.
    Set FFMPEG_LIVE_BUILD_DIR and FFMPEG_LIVE_INSTALL_DIR to override.
    FFMPEG_LIVE_BUILD_JOBS defaults to 8.
    These are small software decoding test builds, not full transcode packages.

compile-probes.sh
    Compile probes against FFMPEG_LIVE_INSTALL_DIR. Build scripts call this.
    FFMPEG_LIVE_SANITIZE is passed to the probe compiler when set.

latency_probe.c
    Original send-then-receive-until-EAGAIN paced-input baseline measurement.
    Existing immutable baseline measurements are in baseline/.

async_probe.c
    Event-driven async/legacy comparison, timestamped packet latency, SHA256,
    PTS/DTS/metadata, actual overlapping codec callbacks, bounded queue retry,
    pause, gate, lifecycle and corrupt-input recovery. Linux uses eventfd/poll;
    Windows uses native events. Slow test callbacks live in the probe, not in
    production library code.

generate-extra-fixtures.ps1
    Generate resize, 10-bit and all-intra synthetic inputs using a full external
    FFmpeg. The original four B=0/B=3 fixtures are generated by test-msys2.sh.
    Frozen fixtures and golden hashes are included separately in the offline
    delivery. Never regenerate a fixture and compare it with unrelated goldens.

test-async.sh
    Requires FFMPEG_LIVE_INSTALL_DIR and FFMPEG_LIVE_RESULT_DIR.
    Defaults for FFMPEG_LIVE_FIXTURE_DIR and FFMPEG_LIVE_BASELINE_RESULT_DIR
    point at sibling results-msys2-baseline and platform baseline directories.
    Every process has a 45-second watchdog. Uses the same probe for paced legacy
    and async measurements at 2/4/8/12 threads. Correctness also compares pixel
    hashes/PTS against saved unmodified 7.0.3 outputs.
    Requires all extended fixtures; missing media is an error, not a skipped test.

validate_async.py
    Enforces legacy equality, frozen original-baseline equality, expected frame
    counts/dimensions, repeated drain/flush, closed-gate nonblocking behavior,
    error recovery and multiple active decoder callbacks. Writes summary.csv.
    Callback overlap includes reference waits and is not a CPU utilization claim.
    No timing pass threshold is used, except the input-pause watchdog condition.

test-linux.sh / test-msys2.sh / summarize_probe.py
    Original baseline workflow, retained for reference. Frozen baseline build
    scripts are available at commit 199fc48. Do not overwrite the baseline
    installation or goldens while testing the modified implementation.

Linux example from the source root:
    export FFMPEG_LIVE_INSTALL_DIR="$PWD/../install-linux-async"
    export FFMPEG_LIVE_RESULT_DIR="$PWD/../results-linux-async"
    bash tools/live-async/build-linux.sh
    bash tools/live-async/test-async.sh

MSYS2 example:
    export FFMPEG_LIVE_INSTALL_DIR=/d/Code/ffmpeg_live/install-msys2-async
    export FFMPEG_LIVE_RESULT_DIR=/d/Code/ffmpeg_live/results-msys2-async
    bash /d/Code/ffmpeg_live/ffmpeg-7.0.3/tools/live-async/build-msys2.sh
    bash /d/Code/ffmpeg_live/ffmpeg-7.0.3/tools/live-async/test-async.sh

Linux AddressSanitizer:
    Set separate build/install/result directories and FFMPEG_LIVE_SANITIZE=address.
    Set ASAN_OPTIONS=detect_leaks=1:halt_on_error=1, then run build and test.
    Assembly is disabled in sanitizer builds to avoid FFmpeg 7.0.3's GCC ASan
    symbol-prefix detection issue. Those timings are not benchmark results.
    TSan failed at configure's empty-executable test in this WSL environment.

Results:
    baseline/ contains original-decoder measurement summaries.
    validation/ contains captured modified/legacy comparison summaries and limits.
    Full per-frame logs and generated media remain in sibling results directories
    and are supplied with the offline validation bundle.
